# Algorithm: Flynn's Classification & Parallel Processing Demonstration


**1. Initialization & Platform Detection**
```
1.1. At compile time, detect CPU architecture:
     - If x86/x64: Enable SSE intrinsics
     - If ARM64: Enable NEON intrinsics
     - Otherwise: Use scalar fallback
1.2. Define constants: VEC=4 (vector size), MAT=2 (matrix dimension), N_TASKS=4 (thread count)
```

**2. Flynn's Classification Demonstrations**

**2.1 SISD (Single Instruction, Single Data)**
```
INPUT: Two scalar floats (a, b)
PROCESS:
  2.1.1. Perform single addition: result = a + b
  2.1.2. Print the result
OUTPUT: One scalar sum
```

**2.2 SIMD (Single Instruction, Multiple Data)**
```
INPUT: Two float vectors A[4] and B[4]
PROCESS:
  2.2.1. IF SSE available:
           - Load 4 floats from A into 128-bit register (_mm_loadu_ps)
           - Load 4 floats from B into 128-bit register
           - Add all 4 pairs simultaneously (_mm_add_ps)
           - Store result to R[4] (_mm_storeu_ps)
  2.2.2. ELSE IF NEON available:
           - Use equivalent ARM intrinsics (vld1q_f32, vaddq_f32, vst1q_f32)
  2.2.3. ELSE (fallback):
           - FOR i = 0 to 3: R[i] = A[i] + B[i]
OUTPUT: Result vector R[4] with element-wise sums
```

**2.3 MISD (Multiple Instruction, Single Data)**
```
INPUT: One scalar float (d)
PROCESS:
  2.3.1. Apply three different operations to the same data:
           - Operation 1: d + 10
           - Operation 2: d * 2
           - Operation 3: d - 5
  2.3.2. Print all results
OUTPUT: Three different transformations of the same input
```

**2.4 MIMD (Multiple Instruction, Multiple Data)**
```
INPUT: Array of 4 floats (data[4])
PROCESS:
  2.4.1. Initialize mutex for thread-safe printing
  2.4.2. FOR i = 0 to 3:
           - Create task structure with {id=i, data=data[i], mutex_ptr}
           - Spawn thread i running mimd_worker()
  2.4.3. Each thread executes a DIFFERENT operation based on id:
           - Thread 0: result = data² (square)
           - Thread 1: result = data + 100
           - Thread 2: result = data / 3
           - Thread 3: result = data * 2.5
  2.4.4. Threads acquire mutex, print result, release mutex
  2.4.5. Main thread joins all worker threads
  2.4.6. Destroy mutex
OUTPUT: 4 results from different operations on different data
```

**3. SIMD Vector Operations**

**3.1 Vector Addition & Multiplication**
```
INPUT: Two vectors A[4], B[4]
PROCESS:
  3.1.1. Perform SIMD addition (same as 2.2)
  3.1.2. Perform SIMD multiplication:
           - Use _mm_mul_ps (SSE) or vmulq_f32 (NEON)
           - R[i] = A[i] * B[i] for all i simultaneously
OUTPUT: Sum vector and product vector
```

**4. SIMD Matrix Multiplication**

```
INPUT: Two 2×2 matrices A and B
PROCESS:
  4.1. Initialize result matrix R[2][2] = zeros
  4.2. FOR each row i (0 to 1):
         FOR each column k (0 to 1):
           4.2.1. Create broadcast vector: a_bc = [A[i][k], A[i][k], 0, 0]
           4.2.2. Create row vector: b_rw = [B[k][0], B[k][1], 0, 0]
           4.2.3. SIMD multiply: p = a_bc × b_rw (element-wise)
           4.2.4. Accumulate: R[i][0] += p[0], R[i][1] += p[1]
OUTPUT: Result matrix R = A × B
```

**5. Parallel vs Sequential Performance Comparison**

```
INPUT: Array of 4 floats (inputs[4])
PROCESS:
  5.1. SEQUENTIAL EXECUTION:
         5.1.1. Record start time
         5.1.2. FOR i = 0 to 3:
                  v = inputs[i]
                  FOR j = 0 to 999,999:
                    v = v * 1.000001 + 0.000001  // CPU-intensive work
                  Print result
         5.1.3. Record end time → calculate seq_time

  5.2. PARALLEL EXECUTION:
         5.2.1. Record start time
         5.2.2. FOR i = 0 to 3:
                  Create thread i with same computation
         5.2.3. Wait for all threads to complete (join)
         5.2.4. Record end time → calculate par_time

  5.3. CALCULATE METRICS:
         Speedup = seq_time / par_time
         Efficiency = (Speedup / N_TASKS) × 100%

OUTPUT: Sequential time, Parallel time, Speedup factor, Efficiency percentage
```
