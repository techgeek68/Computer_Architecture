# Algorithm: Parallel Processing and SIMD Operations


## Section 1: Flynn's Classification

**1.1: SISD Demonstration**

```
ALGORITHM: SISD_Demo(a, b)

INPUT: Two scalar floating-point values a, b
OUTPUT: Sum of a and b

BEGIN
    result ← a + b
    DISPLAY "[SISD] Scalar ADD: a + b = result"
    DISPLAY "Description: Single instruction operates on single data element"
END
```

**1.2: SIMD Demonstration (Vector Addition)**

```
ALGORITHM: SIMD_Demo(A[], B[])

INPUT: Two vectors A and B, each containing 4 floating-point elements
OUTPUT: Result vector R where R[i] = A[i] + B[i]

BEGIN
    DECLARE R[4] as float array
    
    IF hardware supports SSE THEN
        // x86 SIMD: Load 4 floats, add in parallel, store result
        va ← SIMD_LOAD(A)           // Load 4 floats into 128-bit register
        vb ← SIMD_LOAD(B)           // Load 4 floats into 128-bit register
        vr ← SIMD_ADD(va, vb)       // Add 4 pairs simultaneously
        SIMD_STORE(R, vr)           // Store 4 results
        DISPLAY "Hardware: x86 SSE _mm_add_ps (1 instruction, 4 additions)"
        
    ELSE IF hardware supports NEON THEN
        // ARM SIMD: Load 4 floats, add in parallel, store result
        va ← NEON_LOAD(A)
        vb ← NEON_LOAD(B)
        vr ← NEON_ADD(va, vb)
        NEON_STORE(R, vr)
        DISPLAY "Hardware: ARM NEON vaddq_f32 (1 instruction, 4 additions)"
        
    ELSE
        // Scalar fallback
        FOR i ← 0 TO 3 DO
            R[i] ← A[i] + B[i]
        END FOR
        DISPLAY "WARNING: No SIMD ISA detected, using scalar fallback"
    END IF
    
    FOR i ← 0 TO 3 DO
        DISPLAY "R[i] = A[i] + B[i] = R[i]"
    END FOR
END
```

**1.4: MIMD Demonstration**

```
ALGORITHM: MIMD_Demo(data[])

INPUT: Array of 4 floating-point values
OUTPUT: Results from 4 parallel threads executing different operations

BEGIN
    DECLARE threads[4] as pthread_t
    DECLARE tasks[4] as task structure
    DECLARE mutex as pthread_mutex_t
    
    INITIALIZE mutex
    
    DISPLAY "[MIMD] 4 threads, different instructions, different data:"
    
    FOR i ← 0 TO 3 DO
        tasks[i].id ← i
        tasks[i].data ← data[i]
        tasks[i].mutex ← address of mutex
        CREATE_THREAD(threads[i], MIMD_Worker, tasks[i])
    END FOR
    
    FOR i ← 0 TO 3 DO
        JOIN_THREAD(threads[i])
    END FOR
    
    DESTROY mutex
END

ALGORITHM: MIMD_Worker(task)

INPUT: Task structure containing id, data, mutex pointer
OUTPUT: Computed result based on thread ID

BEGIN
    SWITCH task.id MOD 4
        CASE 0: result ← task.data × task.data    // SQUARE
        CASE 1: result ← task.data + 100          // ADD_100
        CASE 2: result ← task.data ÷ 3            // DIV_3
        CASE 3: result ← task.data × 2.5          // MUL_2.5
    END SWITCH
    
    LOCK(task.mutex)
    DISPLAY "Thread task.id: operation(task.data) = result"
    UNLOCK(task.mutex)
END
```



## Section 2: SIMD Vector Operations

**2.1: SIMD Vector Addition**

```
ALGORITHM: SIMD_Vector_Add(A[], B[])

INPUT: Two vectors A and B, each containing 4 floating-point elements
OUTPUT: Result vector R where R[i] = A[i] + B[i]

BEGIN
    DECLARE R[4] as float array
    
    DISPLAY "--- SIMD Vector Addition ---"
    
    IF hardware supports SSE THEN
        va ← _mm_loadu_ps(A)         // Load 4 floats from A
        vb ← _mm_loadu_ps(B)         // Load 4 floats from B
        vr ← _mm_add_ps(va, vb)      // Parallel add: 4 additions in 1 instruction
        _mm_storeu_ps(R, vr)         // Store 4 results to R
        DISPLAY "Hardware: x86 SSE _mm_add_ps"
        
    ELSE IF hardware supports NEON THEN
        vr ← vaddq_f32(vld1q_f32(A), vld1q_f32(B))
        vst1q_f32(R, vr)
        DISPLAY "Hardware: ARM NEON vaddq_f32"
        
    ELSE
        FOR i ← 0 TO 3 DO
            R[i] ← A[i] + B[i]
        END FOR
        DISPLAY "WARNING: No SIMD, scalar fallback"
    END IF
    
    DISPLAY "Operation: 4 parallel additions in 1 instruction"
    DISPLAY "Input A:  [ A[0] A[1] A[2] A[3] ]"
    DISPLAY "Input B:  [ B[0] B[1] B[2] B[3] ]"
    DISPLAY "Result R: [ R[0] R[1] R[2] R[3] ]"
END
```

**2.2: SIMD Vector Multiplication**

```
ALGORITHM: SIMD_Vector_Mul(A[], B[])

INPUT: Two vectors A and B, each containing 4 floating-point elements
OUTPUT: Result vector R where R[i] = A[i] × B[i]

BEGIN
    DECLARE R[4] as float array
    
    DISPLAY "--- SIMD Vector Multiplication ---"
    
    IF hardware supports SSE THEN
        va ← _mm_loadu_ps(A)         // Load 4 floats from A
        vb ← _mm_loadu_ps(B)         // Load 4 floats from B
        vr ← _mm_mul_ps(va, vb)      // Parallel multiply: 4 multiplications in 1 instruction
        _mm_storeu_ps(R, vr)         // Store 4 results to R
        DISPLAY "Hardware: x86 SSE _mm_mul_ps"
        
    ELSE IF hardware supports NEON THEN
        vr ← vmulq_f32(vld1q_f32(A), vld1q_f32(B))
        vst1q_f32(R, vr)
        DISPLAY "Hardware: ARM NEON vmulq_f32"
        
    ELSE
        FOR i ← 0 TO 3 DO
            R[i] ← A[i] × B[i]
        END FOR
        DISPLAY "WARNING: No SIMD, scalar fallback"
    END IF
    
    DISPLAY "Operation: 4 parallel multiplications in 1 instruction"
    DISPLAY "Input A:  [ A[0] A[1] A[2] A[3] ]"
    DISPLAY "Input B:  [ B[0] B[1] B[2] B[3] ]"
    DISPLAY "Result R: [ R[0] R[1] R[2] R[3] ]"
END
```



## Section 3: SIMD Matrix Multiplication

**3.1: SIMD Matrix Multiplication (2×2)**

```
ALGORITHM: SIMD_MatMul(A[2][2], B[2][2])

INPUT: Two 2×2 matrices A and B
OUTPUT: Result matrix R = A × B

BEGIN
    DECLARE R[2][2] as float matrix initialized to 0
    
    DISPLAY "--- SIMD Matrix Multiplication (2×2) ---"
    
    FOR i ← 0 TO 1 DO                    // For each row of A
        FOR k ← 0 TO 1 DO                // For each column of A / row of B
        
            IF hardware supports SSE THEN
                // Broadcast A[i][k] and load B row k
                a_broadcast[4] ← {A[i][k], A[i][k], 0, 0}
                b_row[4] ← {B[k][0], B[k][1], 0, 0}
                
                // SIMD parallel multiplication
                va ← _mm_loadu_ps(a_broadcast)
                vb ← _mm_loadu_ps(b_row)
                vp ← _mm_mul_ps(va, vb)      // 2 multiplications in parallel
                _mm_storeu_ps(p, vp)
                
                R[i][0] ← R[i][0] + p[0]
                R[i][1] ← R[i][1] + p[1]
                
            ELSE IF hardware supports NEON THEN
                // Similar NEON implementation
                a_broadcast[4] ← {A[i][k], A[i][k], 0, 0}
                b_row[4] ← {B[k][0], B[k][1], 0, 0}
                
                vp ← vmulq_f32(vld1q_f32(a_broadcast), vld1q_f32(b_row))
                vst1q_f32(p, vp)
                
                R[i][0] ← R[i][0] + p[0]
                R[i][1] ← R[i][1] + p[1]
                
            ELSE
                // Scalar fallback
                R[i][0] ← R[i][0] + A[i][k] × B[k][0]
                R[i][1] ← R[i][1] + A[i][k] × B[k][1]
            END IF
            
        END FOR
    END FOR
    
    DISPLAY "Matrix A:"
    DISPLAY "  [ A[0][0]  A[0][1] ]"
    DISPLAY "  [ A[1][0]  A[1][1] ]"
    
    DISPLAY "Matrix B:"
    DISPLAY "  [ B[0][0]  B[0][1] ]"
    DISPLAY "  [ B[1][0]  B[1][1] ]"
    
    DISPLAY "Result (A × B):"
    DISPLAY "  [ R[0][0]  R[0][1] ]"
    DISPLAY "  [ R[1][0]  R[1][1] ]"
END
```


## Section 4: Parallel Processing and Performance Comparison

**4.1: Parallel Processing Demonstration**

```
ALGORITHM: Parallel_Demo(inputs[])

INPUT: Array of 4 floating-point values as initial inputs
OUTPUT: Performance comparison between sequential and parallel execution

BEGIN
    DECLARE threads[4] as pthread_t
    DECLARE tasks[4] as task structure
    DECLARE mutex as pthread_mutex_t
    DECLARE seq_results[4] as float array
    
    INITIALIZE mutex
    
    DISPLAY "--- Parallel Processing Performance Comparison ---"
    DISPLAY "Workload: 1,000,000 floating-point operations per task"
    DISPLAY "Tasks: 4 independent computational tasks"
    
    // ========== SEQUENTIAL EXECUTION ==========
    DISPLAY "Sequential execution:"
    
    seq_start_time ← GET_CURRENT_TIME()
    
    FOR i ← 0 TO 3 DO
        v ← inputs[i]
        FOR j ← 0 TO 999999 DO
            v ← v × 1.000001 + 0.000001
        END FOR
        seq_results[i] ← v
        DISPLAY "Task i: inputs[i] -> seq_results[i]"
    END FOR
    
    seq_end_time ← GET_CURRENT_TIME()
    seq_duration ← seq_end_time - seq_start_time    // in microseconds
    
    // ========== PARALLEL EXECUTION ==========
    DISPLAY "Parallel execution (4 threads):"
    
    par_start_time ← GET_CURRENT_TIME()
    
    FOR i ← 0 TO 3 DO
        tasks[i].id ← i
        tasks[i].input ← inputs[i]
        tasks[i].mutex ← address of mutex
        CREATE_THREAD(threads[i], Parallel_Worker, tasks[i])
    END FOR
    
    FOR i ← 0 TO 3 DO
        JOIN_THREAD(threads[i])
    END FOR
    
    par_end_time ← GET_CURRENT_TIME()
    par_duration ← par_end_time - par_start_time    // in microseconds
    
    // ========== PERFORMANCE RESULTS ==========
    speedup ← seq_duration ÷ par_duration
    efficiency ← (speedup ÷ 4) × 100                // 4 threads
    
    DISPLAY "--- Performance Results ---"
    DISPLAY "Sequential time: seq_duration microseconds"
    DISPLAY "Parallel time:   par_duration microseconds"
    DISPLAY "Speedup:         speedup×"
    DISPLAY "Efficiency:      efficiency%"
    
    DESTROY mutex
END
```

**4.2: Parallel Worker Thread**

```
ALGORITHM: Parallel_Worker(task)

INPUT: Task structure containing id, input value, output, mutex pointer
OUTPUT: Computed result after 1,000,000 iterations

BEGIN
    v ← task.input
    
    // Intensive floating-point computation
    FOR i ← 0 TO 999999 DO
        v ← v × 1.000001 + 0.000001
    END FOR
    
    task.output ← v
    
    // Thread-safe output
    LOCK(task.mutex)
    DISPLAY "Task task.id: task.input -> task.output"
    UNLOCK(task.mutex)
END
```

# Steps to Run Parallel Processing and SIMD Operations Code

---

**Running in DevC++**

**Step 1: Install DevC++**
  1. Download Dev-C++ from: https://sourceforge.net/projects/orwelldevcpp/
  2. Run the installer and follow the installation wizard
  3. Select "Full Installation" to include MinGW compiler
  4. Complete the installation

**Step 2: Configure DevC++ for Pthreads**

Since the code uses POSIX threads (pthreads), you need to configure the compiler:

  1. Open Dev-C++
  2. Go to **Tools** → **Compiler Options**
  3. Click on the **General** tab
  4. Check the box **"Add the following commands when calling the compiler"**
  5. In the text field, add:
   ```
   -pthread
   ```
6. Click **OK** to save

**Step 3: Create a New Project**

  1. Go to **File** → **New** → **Project**
  2. Select **Console Application**
  3. Choose **C Project** (not C++)
  4. Enter project name: `Parallel_SIMD_Lab`
  5. Click **OK**
  6. Choose a location to save the project
  7. Click **Save**

**Step 4: Add the Source Code**

  1. DevC++ will create a default `main.c` file
  2. Delete all the default code in `main.c`
  3. Copy and paste the complete source code:
  4. Save the file (**Ctrl + S**)

**Step 5: Configure Project for Pthreads Linking**

1. Go to **Project** → **Project Options**
2. Click on the **Parameters** tab
3. In the **Linker** field, add:
   ```
   -lpthread
   ```
4. Click **OK**


**Step 6: Enable SSE Instructions**

1. Go to **Tools** → **Compiler Options**
2. In the **"Add the following commands when calling the compiler"** field, update to:
   ```
   -pthread -msse4.1
   ```
3. Click **OK**


**Step 7: Compile the Code**
  1. Press **F9** or go to **Execute** → **Compile**
  2. Check the **Compile Log** at the bottom for any errors
  3. If successful, you'll see: `Compilation successful`

**Step 8: Run the Program**

1. Press **F10** or go to **Execute** → **Run**
2. A console window will open
3. Enter the sample inputs.
