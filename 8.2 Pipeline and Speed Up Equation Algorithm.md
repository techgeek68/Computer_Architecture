## Algorithm: Pipelined Floating Point Arithmetic & Speedup Analysis

---

**1: Floating Point Pipeline Execution**

```
Algorithm: FP_PIPELINE
Input: Operand A, Operand B, Operation (+ or -)
Output: Result of floating point operation

1. BEGIN
2. // Split IEEE 754 representation
3. CALL FP_SPLIT(A) → (sign_a, exp_a, mant_a)
4. CALL FP_SPLIT(B) → (sign_b, exp_b, mant_b)
5. COMPUTE true_exp_a = exp_a - 127
6. COMPUTE true_exp_b = exp_b - 127

7. // ========== STAGE 1: COMPARE ==========
8. COMPUTE diff = true_exp_a - true_exp_b
9. IF diff < 0 THEN
10.    SWAP (sign_a, exp_a, mant_a) WITH (sign_b, exp_b, mant_b)
11.    SET diff = -diff
12.    SET result_exp = true_exp_b
13. ELSE
14.    SET result_exp = true_exp_a
15. END IF

16. // ========== STAGE 2: ALIGN ==========
17. SET mant_large = (1 << 23) OR mant_a    // Add implicit 1
18. SET mant_small = ((1 << 23) OR mant_b) >> diff  // Right shift to align

19. // ========== STAGE 3: OPERATE ==========
20. IF operation = '+' THEN
21.    SET effective_sub = (sign_a ≠ sign_b)
22. ELSE
23.    SET effective_sub = (sign_a = sign_b)
24. END IF

25. IF effective_sub = TRUE THEN
26.    IF mant_large ≥ mant_small THEN
27.        SET mant_result = mant_large - mant_small
28.        SET sign_result = sign_a
29.    ELSE
30.        SET mant_result = mant_small - mant_large
31.        SET sign_result = NOT sign_a
32.    END IF
33. ELSE
34.    SET mant_result = mant_large + mant_small
35.    SET sign_result = sign_a
36. END IF

37. // ========== STAGE 4: NORMALIZE ==========
38. SET shift = 0
39. IF mant_result = 0 THEN
40.    SET result_exp = -127
41. ELSE IF mant_result >> 24 ≠ 0 THEN  // Overflow
42.    SET mant_result = mant_result >> 1
43.    SET result_exp = result_exp + 1
44.    SET shift = -1
45. ELSE
46.    WHILE mant_result AND NOT(mant_result >> 23) DO
47.        SET mant_result = mant_result << 1
48.        SET result_exp = result_exp - 1
49.        SET shift = shift + 1
50.    END WHILE
51. END IF

52. // ========== STAGE 5: ROUND ==========
53. SET mant_result = mant_result AND 0x7FFFFF  // Mask to 23 bits

54. // Reconstruct result
55. CALL FP_JOIN(sign_result, result_exp + 127, mant_result) → result
56. COMPUTE expected = A op B  // Using hardware FP
57. COMPUTE error = |result - expected|

58. DISPLAY result, expected, error
59. RETURN result
60. END
```


**2: Speedup Analysis**

```
Algorithm: SPEEDUP_ANALYSIS
Input: k (pipeline stages), n (number of operations), stalls
Output: Speedup metrics

1. BEGIN
2. // Calculate execution times
3. COMPUTE T_sequential = k × n
4. COMPUTE T_pipelined = k + n - 1 + stalls

5. // Calculate speedup
6. COMPUTE Speedup (S) = T_sequential / T_pipelined

7. // Calculate additional metrics
8. COMPUTE Efficiency = (S / k) × 100%
9. COMPUTE Throughput = n / T_pipelined
10. COMPUTE CPI = T_pipelined / n
11. COMPUTE Cycles_Saved = T_sequential - T_pipelined
12. SET Max_Speedup = k  // Theoretical maximum as n → ∞

13. DISPLAY all computed metrics
14. END
```


**3: Speedup Table Generation**

```
Algorithm: SPEEDUP_TABLE
Input: k (pipeline stages)
Output: Table showing speedup for various n values

1. BEGIN
2. DEFINE n_values[] = {1, 2, 5, 10, 20, 50, 100, 200, 500, 1000}

3. DISPLAY table header

4. FOR i = 0 TO 9 DO
5.     SET n = n_values[i]
6.     COMPUTE T_seq = k × n
7.     COMPUTE T_pipe = k + n - 1
8.     COMPUTE Speedup = T_seq / T_pipe
9.     COMPUTE Efficiency = (Speedup / k) × 100%
10.    COMPUTE Savings = (1 - T_pipe / T_seq) × 100%
11.    DISPLAY row: n, T_seq, T_pipe, Speedup, Efficiency, Savings
12. END FOR

13. DISPLAY theoretical limit row (n = ∞, Speedup = k)
14. END
```


**4: Pipeline Diagram Generation**

```
Algorithm: PIPELINE_DIAGRAM
Input: k (stages, max 8), n (operations, max 10)
Output: Visual space-time diagram

1. BEGIN
2. DEFINE stage_names[] = {"IF", "ID", "EX", "MM", "WB", "S6", "S7", "S8"}
3. SET stages = MIN(k, 8)
4. SET ops = MIN(n, 10)
5. COMPUTE total_cycles = stages + ops - 1

6. // Display configuration
7. DISPLAY "Config: k stages, n operations"
8. DISPLAY stage names connected by arrows

9. // Display header row (cycle numbers)
10. DISPLAY "     |"
11. FOR c = 1 TO total_cycles DO
12.    DISPLAY "C" + c + "|"
13. END FOR

14. // Display instruction execution grid
15. FOR i = 0 TO ops - 1 DO
16.    DISPLAY "I" + (i+1) + " |"
17.    FOR c = 0 TO total_cycles - 1 DO
18.        SET stage_index = c - i
19.        IF stage_index ≥ 0 AND stage_index < stages THEN
20.            DISPLAY stage_names[stage_index] + "|"
21.        ELSE
22.            DISPLAY " . |"
23.        END IF
24.    END FOR
25.    NEWLINE
26. END FOR

27. // Display active instructions per cycle
28. DISPLAY "Act |"
29. FOR c = 0 TO total_cycles - 1 DO
30.    SET active_count = 0
31.    FOR i = 0 TO ops - 1 DO
32.        SET stage_index = c - i
33.        IF stage_index ≥ 0 AND stage_index < stages THEN
34.            SET active_count = active_count + 1
35.        END IF
36.    END FOR
37.    DISPLAY active_count + "|"
38. END FOR

39. // Display summary
40. COMPUTE T_seq = k × n
41. COMPUTE T_pipe = k + n - 1
42. COMPUTE Speedup = T_seq / T_pipe
43. COMPUTE Efficiency = (Speedup / k) × 100%
44. DISPLAY T_seq, T_pipe, Speedup, Efficiency
45. END
```
