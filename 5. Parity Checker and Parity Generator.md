**Theory**

Combinational logic circuits are digital circuits whose outputs depend solely on the current input values, with no memory or feedback. They are constructed using basic logic gates and are used to implement Boolean functions. In this experiment, two important combinational circuits are studied:

- **Parity Checker:** Detects whether the number of 1s in a set of input bits is even or odd.
- **Parity Generator:** Generates an additional parity bit to be appended to a data word for error detection purposes.

**Parity** is a simple error detection mechanism used in digital communication and storage systems. There are two types:
- **Even Parity:** The total number of 1s (including the parity bit) is even.
- **Odd Parity:** The total number of 1s (including the parity bit) is odd.

Both circuits use the XOR operation as their fundamental building block, since XOR produces a 1 only when an odd number of its inputs are 1.

    port (

        p              : out std_logic

**VHDL Code:**

```vhdl name=parity_generator.vhd
library ieee;
use ieee.std_logic_1164.all;

entity paritygen is
    port (
        a0, a1, a2, a3 : in  std_logic;
        p_odd, p_even  : out std_logic
    );
end paritygen;

architecture dataflow of paritygen is
begin
    process (a0, a1, a2, a3)
    begin
        -- Odd parity: 1 if odd number of 1s in inputs
        p_odd  <= ((a0 xor a1) xor a2) xor a3;
        -- Even parity: 1 if even number of 1s in inputs
        p_even <= not(((a0 xor a1) xor a2) xor a3);
    end process;
end dataflow;
```
