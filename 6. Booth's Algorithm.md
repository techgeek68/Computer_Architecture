## Booth's Algorithm for Multiplication

**Objective**
  - Write a C program to implement Booth's Algorithm for the multiplication of two signed binary numbers.

**Theory**

The algorithm is based on the observation that any binary number can be represented by the sum and difference of other binary numbers. Specifically, a string of consecutive 1's in the multiplier can be replaced by a subtraction at the low order end and an addition at the high order end.

For example, the binary number `0111` (decimal 7) can be represented as `1000 − 0001` (i.e., 8 − 1). This means that instead of performing three additions (for three 1 bits), we can perform one subtraction and one addition.

Booth's algorithm serves two primary purposes:

  1. Fast multiplication: When there are consecutive 0's or 1's in the multiplier, it reduces the number of addition/subtraction operations required.
     
  2. Signed multiplication: it natively handles signed numbers in two's complement representation without requiring separate sign handling.

**Algorithm Procedure**

Booth's algorithm examines adjacent pairs of bits of the N-bit multiplier **Q** in signed two's complement representation, including an implicit bit below the least significant bit: **Q₋₁ = 0**.

For each bit position **i**, running from 0 to N−1, the bits **Qᵢ** and **Qᵢ₋₁** are examined:

| Qᵢ | Qᵢ₋₁ | Operation |
|-----|-------|-----------|
| 0   | 0     | No operation (Arithmetic Right Shift only) |
| 0   | 1     | Add multiplicand M to accumulator P, then Arithmetic Right Shift |
| 1   | 0     | Subtract multiplicand M from accumulator P, then Arithmetic Right Shift |
| 1   | 1     | No operation (Arithmetic Right Shift only) |

After all N iterations, the combined register **[P : Q]** contains the signed product in two's complement form.

**Arithmetic Right Shift (ASR)**

In each step, the combined register **[P : Q]** is arithmetically right shifted by one position. In an arithmetic right shift:

  - All bits shift one position to the right.
  - The **sign bit (MSB) is preserved**;it is copied into the vacated position.
  - The LSB of P shifts into the MSB of Q.
  - The previous Q₋₁ is replaced by the old LSB of Q.

**Example: 4 × 6**
```
M (Multiplicand) = 6  →  00110
-M               = -6 →  11010
Q (Multiplier)   = 4  →  00100
Q₋₁              = 0

Step 1: Q₀=0, Q₋₁=0 → No operation, ASR
  P:Q    = 00000:00100 → ASR → 00000:00010,  Q₋₁=0

Step 2: Q₀=0, Q₋₁=0 → No operation, ASR
  P:Q    = 00000:00010 → ASR → 00000:00001,  Q₋₁=0

Step 3: Q₀=1, Q₋₁=0 → Subtract M (P = P - M)
  P      = 00000 + 11010 = 11010
  P:Q    = 11010:00001 → ASR → 11101:00000,  Q₋₁=1

Step 4: Q₀=0, Q₋₁=1 → Add M (P = P + M)
  P      = 11101 + 00110 = 00011
  P:Q    = 00011:00000 → ASR → 00001:10000,  Q₋₁=0

Step 5: Q₀=0, Q₋₁=0 → No operation, ASR
  P:Q    = 00001:10000 → ASR → 00000:11000,  Q₋₁=0

Final Product: P:Q = 00000:11000 = 0000011000₂ = 24₁₀ ✓
```

**Algorithm**
```
1.  Start
2.  Read two decimal numbers: A (multiplier), B (multiplicand)
3.  Convert A and B into N-bit two's complement binary representations
4.  Compute −B (two's complement of B) and store as B_comp
5.  Initialize:
      Product register P = 0 (N bits)
      Q = A (N-bit multiplier)
      Q₋₁ = 0
6.  Repeat for i = 0 to N−1:
      a. If Q₀ == 0 and Q₋₁ == 0:
           Arithmetic Right Shift [P : Q : Q₋₁]
      b. Else if Q₀ == 0 and Q₋₁ == 1:
           P = P + B (Add multiplicand)
           Arithmetic Right Shift [P : Q : Q₋₁]
      c. Else if Q₀ == 1 and Q₋₁ == 0:
           P = P + B_comp (Subtract multiplicand)
           Arithmetic Right Shift [P : Q : Q₋₁]
      d. Else (Q₀ == 1 and Q₋₁ == 1):
           Arithmetic Right Shift [P : Q : Q₋₁]
7.  Final result is [P : Q] (2N-bit signed product)
8.  Convert the result to a decimal and display
9.  End
```

**Observations**

  1. **Positive × Positive:** The algorithm correctly produces a positive product (Test Case 1: A = 4, B = 6, Product = 24).

  2. **Negative × Positive:** The algorithm correctly produces a negative product in two's complement form (Test Case 2: A = −3, B = 5, Product = −15). The sign bit (MSB) of the result is 1, indicating a negative number.

  3. **Negative × Negative:** The algorithm correctly produces a positive product (Test Case 3: A = −4, B = −6, Product = 24). The two negative signs cancel out.

  4. **Bit Pattern Optimization:** Booth's algorithm efficiently handles strings of consecutive 1's by converting them to a high order +1 and a low order −1. For example, when multiplying by 7 (`00111`), instead of performing three additions, the algorithm performs one subtraction at bit position 0 and one addition at bit position 3, reducing the number of operations.

  5. **Arithmetic Right Shift:** The sign bit is correctly preserved during every arithmetic right shift, ensuring that two's complement representation is maintained throughout the computation.

**Booth's algorithm has clear advantages over simple shift and add multiplication:**

1. Native signed arithmetic: It works with two's complement signed numbers directly without needing separate steps to detect and fix the sign.
  
2. Optimized operations: By looking at pairs of adjacent bits, strings of 0's or 1's require only shift operations (no addition or subtraction), which reduces the total number of arithmetic operations needed.

3. Uniform procedure: The same algorithm applies to all combinations of positive and negative operands, making the hardware implementation simpler and more consistent.
