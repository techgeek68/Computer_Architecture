# Steps to Run Parallel Processing and SIMD Operations Code

---

## Running in Dev-C++

---

**Step 1: Install Dev-C++**
1. Download Dev-C++ from: https://sourceforge.net/projects/orwelldevcpp/
2. Run the installer and follow the installation wizard
3. Select "Full Installation" to include the MinGW compiler
4. Complete the installation

---

**Step 2: Configure Dev-C++ for Pthreads**

Since the code uses POSIX threads (pthreads), you need to configure the compiler:

1. Open Dev-C++
2. Go to **Tools** > **Compiler Options**
3. Click on the **General** tab
4. Check the box **"Add the following commands when calling the compiler"**
5. In the text field, add:
```
-pthread
```
6. Click **OK** to save

---

**Step 3: Create a New Project**

1. Go to **File** > **New** > **Project**
2. Select **Console Application**
3. Choose **C Project** (not C++)
4. Enter project name: `Parallel_SIMD_Lab`
5. Click **OK**
6. Choose a location to save the project
7. Click **Save**

---

**Step 4: Add the Source Code**

1. Dev-C++ will create a default `main.c` file
2. Delete all the default code in `main.c`
3. Copy and paste the complete source code
4. Save the file (**Ctrl + S**)

---

**Step 5: Configure Project for Pthreads Linking**

1. Go to **Project** > **Project Options**
2. Click on the **Parameters** tab
3. In the **Linker** field, add:
   ```
   -pthread
   ```
4. Click **OK**

---

**Step 6: Enable SSE Instructions (Optional - Based on CPU)**

1. Go to **Tools** > **Compiler Options**
2. In the **"Add the following commands when calling the compiler"** field, update based on your CPU:

   **For modern CPUs (Intel Core 2nd gen+, AMD Bulldozer+):**
   ```
   -pthread -msse4.1 -O2
   ```

   **For older CPUs or if unsure (safe fallback):**
   ```
   -pthread -msse2 -O2
   ```

   **To disable SIMD entirely (pure scalar mode):**
   ```
   -pthread -O2 -DUSE_SSE=0 -DUSE_NEON=0
   ```
3. Click **OK**
   
---

**Step 7: Compile the Code**

1. Press **F9** or go to **Execute** > **Compile**
2. Check the **Compile Log** at the bottom for any errors
3. If successful, you'll see: `Compilation successful`

---

**Step 8: Run the Program**

1. Press **F10** or go to **Execute** > **Run**
2. A console window will open
3. Enter the sample inputs

---

## Running in Visual Studio Code (VS Code)

---

**Step 1: Install VS Code**

1. Download VS Code from: https://code.visualstudio.com/
2. Run the installer and complete the installation
3. Launch VS Code

---

**Step 2: Install Required Extensions**

1. Open VS Code
2. Click the **Extensions** icon in the left sidebar (or press **Ctrl + Shift + X**)
3. Search and install the following extensions:
   - **C/C++** by Microsoft
   - **Code Runner** by Jun Han (optional, for easy running)

---

**Step 3: Install a C Compiler**

**For Windows:**

**Install MinGW-w64 via MSYS2 (Recommended)**

1. Download MSYS2 from: https://www.msys2.org/
2. Run the installer and complete installation
3. Open **MSYS2 MINGW64** terminal (not MSYS2 MSYS) and run:
   ```bash
   pacman -S mingw-w64-x86_64-gcc mingw-w64-x86_64-gdb
   ```
4. Add MinGW bin folder to System PATH:
   - Right click **This PC** > **Properties**
   - Click **Advanced system settings**
   - Click **Environment Variables**
   - Under **System variables**, find **Path** and click **Edit**
   - Click **New** and add: `C:\msys64\mingw64\bin`
   - Click **OK** to save all dialogs
5. **Restart VS Code** (or your computer) for PATH changes to take effect

**For macOS:**

1. Open Terminal
2. Install Xcode Command Line Tools:
   ```bash
   xcode-select --install
   ```
3. **Check your Mac's processor type:**
   ```bash
   uname -m
   ```
   - If output is `x86_64`: You have an Intel Mac
   - If output is `arm64`: You have Apple Silicon (M1/M2/M3/M4)

**For Linux (Ubuntu/Debian):**

1. Open Terminal
2. Run:
   ```bash
   sudo apt update
   sudo apt install build-essential gdb
   ```

---

**Step 4: Verify Compiler Installation**

1. Open VS Code
2. Open Terminal in VS Code: **Terminal** > **New Terminal** (or **Ctrl + `**)
3. Check GCC installation:
   ```bash
   gcc --version
   ```
4. You should see version information if installed correctly


---

**Step 5: Verify SIMD Support (Optional but Recommended)**

Run these commands to check your CPU's SIMD capabilities:

**For Linux:**
```bash
cat /proc/cpuinfo | grep -E "sse4_1|neon" | head -1
```

**For macOS:**
```bash
sysctl -a | grep -E "hw.optional.sse4_1|hw.optional.neon"
```

**For Windows (PowerShell):**
```powershell
wmic cpu get caption, name
```

---

**Step 6: Create Project Folder and File**

1. Create a new folder for your project:
   - **File** > **Open Folder**
   - Create a new folder named `Parallel_SIMD_Lab`
   - Select and open it

2. Create a new file:
   - **File** > **New File** (or **Ctrl + N**)
   - Save as `Parallel_Processing_SIMD.c` (**Ctrl + S**)

3. Copy and paste the complete source code

4. Save the file (**Ctrl + S**)

                "${workspaceFolder}/Parallel_Processing_SIMD.c",
                "-pthread",
                "-msse4.1",
                "-Wall",
                "-O2"

            "group": {
                "kind": "build",
                "isDefault": true
            },
            "problemMatcher": ["$gcc"],
            "detail": "Compile Parallel Processing and SIMD Lab"

**Step 9: Build the Code**

**Method 1: Using Build Task**
1. Press **Ctrl + Shift + B** to run the build task
2. Check the Terminal for compilation output
3. If successful, you'll see no errors

**Method 2: Using Terminal**
1. Open Terminal: **Terminal** > **New Terminal**
2. Run the compilation command:

   **For Windows:**
   ```bash
   gcc -o parallel_simd_lab.exe Parallel_Processing_SIMD.c -pthread -msse4.1 -Wall -O2
   ```

   **For macOS (Intel):**
   ```bash
   gcc -o parallel_simd_lab Parallel_Processing_SIMD.c -pthread -msse4.1 -Wall -O2
   ```

   **For macOS (Apple Silicon):**
   ```bash
   clang -o parallel_simd_lab Parallel_Processing_SIMD.c -pthread -Wall -O2
   ```

   **For Linux:**
   ```bash
   gcc -o parallel_simd_lab Parallel_Processing_SIMD.c -pthread -msse4.1 -Wall -O2 -lm
   ```

---

**Step 10: Run the Program**

**Method 1: Using Terminal**
1. In the VS Code terminal, run:

   **For Windows:**
   ```bash
   .\parallel_simd_lab.exe
   ```

   **For macOS/Linux:**
   ```bash
   ./parallel_simd_lab
   ```
2. Enter sample inputs when prompted

**Method 2: Using Debug Configuration**
1. Press **F5** to start debugging/running
2. An external console will open
3. Enter inputs in the console

**Method 3: Using Code Runner Extension**
1. If you installed the Code Runner extension, first configure it:
   - Go to **File** > **Preferences** > **Settings**
   - Search for `code-runner.executorMap`
   - Click **Edit in settings.json**
   - Add the following configuration:

   **For Windows:**
   ```json
   "code-runner.executorMap": {
       "c": "cd $dir && gcc $fileName -o $fileNameWithoutExt.exe -pthread -msse4.1 -Wall -O2 && $dir$fileNameWithoutExt.exe"
   }
   ```

   **For macOS/Linux:**
   ```json
   "code-runner.executorMap": {
       "c": "cd $dir && gcc $fileName -o $fileNameWithoutExt -pthread -msse4.1 -Wall -O2 && $dir$fileNameWithoutExt"
   }
   ```

2. Right click in the editor
3. Select **Run Code**
