# Simulation of Logic Gates Using VHDL

**Objective:**

To design and simulate the basic logic gates (AND, OR, NOT, NAND, NOR, XOR, and XNOR) using VHDL and verify their functionality by observing truth tables and simulation waveforms.

**Theory**

Logic gates are the fundamental building blocks of all digital systems. A logic gate is an electronic circuit that produces an output based on one or more binary inputs. Each gate performs a specific Boolean operation. In this experiment, the following seven gates are studied:

  - **AND Gate**: Outputs HIGH (1) only when all inputs are HIGH.
  - **OR Gate**: Outputs HIGH (1) when at least one input is HIGH.
  - **NOT Gate**: Inverts the input; outputs the complement.
  - **NAND Gate**: Complement of AND; outputs LOW (0) only when all inputs are HIGH.
  - **NOR Gate**: Complement of OR; outputs HIGH (1) only when all inputs are LOW.
  - **XOR Gate**: Outputs HIGH (1) when the inputs are different.
  - **XNOR Gate**: Outputs HIGH (1) when the inputs are the same.

This exercise forms the foundation for designing more complex combinational and sequential digital circuits using VHDL.
